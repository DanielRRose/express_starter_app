# My Express App

## Description
A simple Express application with prebuild and organized file structure.

## Getting Started

### Prerequisites
- Node.js
- npm

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/DanielRRose/express_starter_app.git
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Set type to "module"
   Make sure to set "type": "module" in package.json, or add if missing.

### Running the App
```bash
npm start
```
